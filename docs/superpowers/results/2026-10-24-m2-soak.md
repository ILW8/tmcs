### Calls to check while trying

#### Graphs

- The x axis is time-based. The window is 59 s, which is Task Manager's 60 samples exactly at Normal. At High it shows 119 points, at Low 16. It freezes while paused. (Sidebar mini graphs and CPU pane.)
- Each graph type keeps a fixed grid step: CPU 10 samples, GPU engines 4, the rest 3. (CPU pane; the rest show from Task 15.)
- Auto-scale picks the smallest step at or above the visible maximum, from fixed lists, with a floor of 100 Kbps or 100 KB/s. (Sidebar network mini graphs; the pane scale captions show from Tasks 16 and 17.)
- The CPU grid shape for processor counts other than 32 is rows = max(1, round(sqrt(n/2))) and columns = ceil(n/rows). (CPU pane. Your PC shows the 32 case.)

#### Numbers

- Network rates use K = 1000. (Sidebar network entries.)
- Percentages and the GPU temperature round half away from zero. (Sidebar.)
- Each GPU engine graph shows the busiest node of that type, for example the max of the six Copy nodes. (Shows from Task 18.)
- The size unit is chosen before rounding, so a value a hair under a unit step shows "1024 MB" instead of "1.0 GB". (Sidebar and panes.)
- In a pair with one decimal, a zero member prints "0.0", for example "0.0/1.6 GB". Task Manager may print "0/1.6 GB". (Sidebar and panes.)
- Speed is not capped at the base speed. It follows boost above it. (CPU pane.)

#### Data

- No D3D device is ever created. The DirectX version comes from the registry's DirectX cache. (Shows from Task 18.)
- Up time comes from the system's boot time. Virtualization shows only Enabled or Disabled. (CPU pane.)
- Several drive letters on one disk are joined by a space. `Removable` follows the `RemovableMedia` flag. (Sidebar disk titles.)
- Wi-Fi signal bars are quality / 20 + 1, at most 5. (Shows from Task 17.)
- A failed process snapshot skips the whole tick, devices included. (Not directly visible.)
- If the GPU engine counters can't be opened, no GPU entry is listed at all, rather than one stuck at 0 %. (Sidebar.)
- A GPU that disappears and comes back without a device-change message stays missing until the next device-change message. (Sidebar.)

#### Sidebar

- `Show hidden adapters` isn't remembered between runs, and N counts only adapters that are present. Hidden adapters themselves are remembered, in the settings file. (Sidebar.)
- `Hide` is a check item, so it also un-hides. (Sidebar.)
- Up and Down move the selection. (Sidebar.)
- When the selected device goes, the selection moves to a same-named device of the same kind, else to the entry above, else to CPU. (Sidebar.)
- When the selected entry and the entries just above it go away in the same rescan, the selection moves to the nearest remaining entry above (for example a disk), not straight to CPU. (Sidebar.)
- The GPU entry's temperature text is black. (Sidebar.)
