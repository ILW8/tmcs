## Task 10: Run new task

**Built.** File > Run new task (before Exit) calls the shell's own Run dialog (`RunFileDlg`, shell32 ordinal 61), as Task Manager does:
- The dialog runs on its own STA thread (`SHCreateThread` with `CTF_COINIT_STA`), so tmcs keeps running while it is open. It gets its own copy of the window icon.
- The flags are Task Manager's (reference 2.2): base 0x14; the admin box (0x40) when not in Safe Mode, `wdc.dll` can start a task as the user, and tmcs is not WOW64; no Browse button when `ShellStyle.dll` is missing.
- Box checked, or no box: the shell starts the command itself.
- Box unchecked: the dialog sends tmcs a `WM_NOTIFY` with code -511. tmcs reads the command, directory and flags at the offsets above and starts the command non-elevated through `wdc.dll!WdcRunTaskAsInteractiveUser`, then answers 1 (close the dialog) or 2 (keep it open).

**What you see.** The dialog "Create new task" with "Open:" and, normally, the admin checkbox. A command that fails to start leaves the dialog open and shows no error, as in Task Manager.

**Rulings and limits.**
- R11 and R12: the payload probe is not retried; the offsets are the reference's. The wdc call always passes flags 0, never 0x40 and never the dialog's DWORD. Both Debug and Release use wdc for the unchecked path (P2).
- R-Y: the 1000x open-and-cancel leak test is waived for the shell's Run dialog, because calling `RunFileDlg` was forbidden in the unattended run. tmcs's own side (the argument block, the icon copy, the thread) is freed on every path.
- R-Z: the offsets stay unverified. See the warning at the top.
- Ctrl+Run new task (Task Manager's "open cmd directly") is left out: the spec does not list it.
- wdc always gets flags 0 (R12).
- There is no direct-start fallback. The implementer wrote one for a missing `wdc.dll`; the final review found it unreachable on Windows 10 (no wdc means no admin box, so the shell starts the command itself) and unsafe (it could start a task elevated in Release), and it was removed. Without wdc, tmcs starts nothing and answers 2.
